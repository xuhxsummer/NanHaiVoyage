# 0.28.11 — 贴图、每日奖励、世界与海战接触

- 港口、岛屿、异兽和草药的 50 张打包插图最大边长提高到 1024。构建始终从 android/assets 原图读取，避免增量构建把旧 512 副本当成源；原图不修改。运行时共用的海图缩略图仍维持 256 方形纹理预算和去底处理。
- 活动入口改为全屏每日登录奖励：每个游戏日领取 200 银两。页面显示当前游戏日、可领取或已领取状态，领取后立即保存银两和 dailyClaimDay；重复点击、重新打开和读档均不会重复发奖。游戏时钟过午夜后可再次领取；页面打开时世界保持暂停。
- 世界从 9600×7200 再扩大到 19200×14400，所有港口和岛屿坐标同步翻倍。小地图地理带和可视范围同步扩大；海图按世界尺寸投影。实体船、陆地、局部战斗/停靠距离保持原尺寸。相机与水面随船定位，原有远裁面与水网格继续覆盖可见范围。
- 存档版本为 3：0.28.10 坐标乘 2，更早坐标乘 4；停靠存档随港口迁移并保持局部停船偏移。再次保存读取不重复缩放。
- HUD 船坞与商行合并为商城。商城保留船只、战船、货船和特种船分类，新增我的船只入口；现有购买、免费换乘及港口内交易继续可用。
- 海盗与玩家最小间距采用双方真实船型的包围半径加 6 个世界单位。玩家移动按短步检测船间接触，去除朝内速度以停止或沿边滑动；海盗追击距离封顶在接触点，长帧也不会穿过玩家。生成、换船或旧重叠状态在渲染前恢复间距，岸边和世界边界优先选择空水面。

验证覆盖：50 张打包图的 1024 尺寸与原图保留；3 个版本的存档坐标迁移及每日奖励午夜/持久化/重复领取；3,672 次陆地碰撞与 34 条长距离自动航线；1,728 次船间高速接近及全部船型/方向、持续追击滑动、岸边/世界角落；全屏每日奖励与商城实际点击购买、账号文件保存、14 个全屏页面的暂停/关闭；真实 GL 海战开火、拾取、模型边界和海图图像重载。
