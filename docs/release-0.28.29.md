# v0.28.29

- 战利品弹窗采用公告样式：深蓝金边、金色标题、居中内容与「收下」按钮；沉船反馈结束后显示，航行世界继续运行。
- 任务对白收紧纸面上下留白，保留宽面板与人物半身像；长句单行横向滚动，切换台词后从句首开始。
- 航行 HUD 的「锁定」可选择视野内最近的海盗、商船或战船，支持取消及点击船只。战船保持锁定目标，旧炮弹不会误伤同槽位新船，击沉奖励与残骸只结算一次。
- 任务列表只显示标题和同行短状态（可领奖／已领），右侧任务详情与航行 HUD 任务卡保留。
- NPC 船速降低并保留船型差异：商船巡航上限 105，逃逸倍率 1.2；海盗与战船基础巡航约 75，追击领先量降至 12。
- 黎明 05:00–07:00、黄昏 17:00–19:00 平滑过渡；天空、水面、环境光和方向光同步更新，船只照明随之变化。

验证包括任务对话、综合 UI 流程、情境指引与战斗反馈、AI 锁定和速度、海上交通及主支线任务回归；检查中文字体覆盖，并构建 Android APK。

APK 仅作为 Release 附件发布，不纳入 Git。
