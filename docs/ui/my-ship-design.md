# 我的 · 船与家当

已阅读 `09-my-ship.md` 和 `00-global-app-layout.md`，打开并对照 `assets/ui-refs/09-my-ship.png`。中央墨蓝铜金面板、朱砂标题签、四项资源横栏、当前船插画与属性、已拥有船队横列、四类货舱摘要及底部换船提示与参考结构对应。复用 QuestUi 与商城船图集，文字全部为 Scene2D 真实数据。

沿用 VoyageScreen 的 `equipShip`、toast、persist、关闭流程；换船不改货物、不收费，容量不足由原 GameState 拒绝并提示。面板延迟创建、重建时复用，保存横向滚动位置；屏幕两个清理路径释放自有纹理，不释放共用字体或 IconLib。
