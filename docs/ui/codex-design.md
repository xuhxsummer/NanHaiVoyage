# 图鉴 overlay

已阅读 00-global-app-layout.md、06-bestiary.md，并打开参考 06-bestiary.png。

1328×784 设计像素的展开图鉴册置于原有航海 HUD 上，以 2/3 比例接入现有视口，对应 1920×1080 横屏构图。左侧深海蓝书签、羊皮纸双页、铜金边框、深色书脊；选中卡和分类采用朱砂强调，发现状态采用玉石青。复用 QuestUi 程序纹理及 IconLib 现有插图，不修改其他页面样式。

左页：异兽/草药分类、真实发现进度、Catalog 默认顺序、3×3 网格、全部/已发现/未发现筛选。现有每类 8 项，空余第九格不表示新增收藏；支持未来超过 9 项时翻页。每类独立记忆选中条目，初次优先选择已发现项。

右页：选中名称、分类与发现状态、已有插图、真实持有数量和 Catalog 卖价。没有数据来源的掉落、具体栖息地及传说标注“暂无记载”；不引入参考图的 18 项总数或虚构掉落物。三足龟遵循真实解锁记录，不强制解锁。

仅读取 beastFound/herbFound/beasts/herbs，不更改任何存档字段。读档替换 GameState 后重新绑定数据。保留原有图鉴入口和关闭行为。

本轮验证仅 core/lwjgl3 compileJava；不运行游戏、截图、APK、打包、版本变更或发布。
