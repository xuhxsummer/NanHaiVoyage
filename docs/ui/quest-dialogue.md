# 主线任务对话（0.28.15）

主线 HUD「任务卡」打开底部对话播放器，右上角「任务」仍打开完整任务日志。下一程卡片显示前序领奖后解锁的提示，不提前标记下一章已播放；全部主线完成后显示续航寄语。

`VoyageScreen.QuestDef.dialogue` 保存每个任务的 `(说话人, 台词)` 数组。十九个任务各有三句原创对白，以武周商旅和《南海见闻录》为主线；老掌柜、船医、船匠、海客、画师等与玩家轮流说话。原 `story` 和 `description` 继续在日志中展示，原任务编号、计数、奖励和解锁链保持一致。

`QuestDialogue` 使用现有 QuestUi 金框、朱红姓名牌与纸面。底部面板高 264 HUD 像素，左右留 18 像素，正文为 28px 无描边字体（QuestUi 按屏幕生命周期生成一次并释放）。全屏半透明遮暗层拦截触摸；正文与空白处每次点击推进一句，按钮独立处理点击，不同时推进对白。

末句之后显示目标，按状态提供一个按钮：完成且未领取时「领奖」，可导航且船只不在暂停状态时「前往」，其余情况「知道了」。末页点击空白仅收起，不自动领奖。右上角「关闭」或 Escape 随时退出；退出与领奖后恢复世界与操控，原自动航行目标保留。迟到的旧领奖回调不能重复发奖或关闭下一章。

`GameState.questDialogueSeen` / `SaveData.questDialogueSeen` 为按任务 ID 的位掩码，属于本机账号存档，旧档缺省为零。在首次展示当前主线时即标记并保存，所以跳过也不会循环弹出；手动点击卡片始终可以重播。新章节成为当前主线后，在没有其它菜单时自动播放一次，教程、港口、任务日志等已有页面不会被抢占。对话使用独立的 DIALOGUE overlay，暂停移动、时钟、战斗并释放已按住的操控；不修改任务进度，也不取消自动航行。

验证：

- `xvfb-run -a ./gradlew :lwjgl3:questDialogueSmoke`：真实触摸与 GL，测试首次播放、逐句推进、遮罩拦截、关闭重播、锁定预告、完整日志、两处领奖入口、下一章、账号存档与宽屏。
- `./gradlew :lwjgl3:questStoryRegression :lwjgl3:autoSailPirateRegression`：十九个任务的奖励与存档兼容、对白长度、播放标记往返，以及海盗出现/脱离/胜利时航线保留。
- `python3 tools/check_ui_font.py`：检查所有对白用字。

截图保存在 gitignored 的 `Builds/dialogue2815/`。没有新增立绘、配音、分支或外部资源包。

## 支线扩展（0.28.16）

追加 ID 19–30 的十二个独立任务，各有三句原创对白：盐风入灶、米香到埠、棉布裁春、胡椒小札、琉璃映潮、一篓乡味、十港邮灯、五屿拾青、清波护渡、三味茶话、万两归帆、异兽旁笺。采用 Catalog 的货物、港口和岛屿名，延续武周商旅与《南海见闻录》的叙述。支线均可独立完成；没有插入主线 unlockAfter 链。

任务列表标明主线/支线，顶部按钮可跳至对应列表。点支线行打开相同的逐句对话，末页「详情 / 领奖」回到对应任务详情；关闭/跳过也返回详情。详情保留进度、奖励、前往和领取按钮，未完成不可领取，重复点击不重复发奖。主线 HUD 与下一程预告都限制在 0–18，支线不会替代当前主线，也不会触发主线自动播放。

`sideQuestClaims` 使用从 ID 19 开始的独立 long 位集；新增 `questGoodsBought` / `questGoodsSold` 按商品保存累计成功交易数量。其余支线复用现有捕鱼、访港、搜采、亲手击败海盗、银两峰值与异兽发现计数。旧档新增字段为零；原主线领取标记及 `questDialogueSeen` 不变。

新增验证：`sideQuestRegression` 检查全部十二条、领奖幂等性、真实交易计数与 JSON 新旧存档；`xvfb-run -a ./gradlew :lwjgl3:sideTrafficSmoke` 检查真实点行、对话推进、详情领取、重播、存档和宽屏。主线 `questStoryRegression` 与 `questDialogueSmoke` 保留原十九条的完整校验。
