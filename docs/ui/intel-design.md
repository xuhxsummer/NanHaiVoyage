# 情报 · 各港价格

已阅读全局规范及 08-intel.md，打开并参考 08-intel.png。

中央面板采用 1200×736 设计像素，8px 网格，以 2/3 比例接入现有 HUD，保持 1920×1080 概念画板。顶部最低价与最高价并列，下方为套利表；沿用海上 HUD 背景。

复用 QuestUi 的铜金 NinePatch、细颗粒羊皮纸表头、深海蓝行、木棕细边和导航按钮，各自持有纹理实例，不改变任务页样式。商品图标复用 IconLib.good。页面文案与价格由 Scene2D 实时绘制，不使用写死价格的整页图。

最低/最高三项的 goodPrice 排序和同价顺序保留；套利仍对每个最低项寻找该商品的最高价港口。玉石青数字表示当前每份差价，不是历史涨跌或实际已获利润。未添加参考图之外的筛选器或虚构趋势。

保留情报低/情报高/情报套行名，整行和前往按钮均调用 autoSailFromIntel：停泊/暂停时提示先离港，海上导航后关闭。套利指向卖出港，无正差价时禁用导航。单次点击只触发一次导航。

本轮仅执行 core/lwjgl3 compileJava；不运行游戏或截图，不生成 APK、不打包、不发布、不修改版本。
