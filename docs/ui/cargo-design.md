# 货舱 overlay

已阅读全局规范和 04-cargo.md，打开并参考 04-cargo.png。参考图使用四类标签和三列表格，按此结构实现，不新增重量或仓储规则。

中央面板 1008×784 设计像素，8px 网格，按 2/3 比例接入现有 HUD，对应 1920×1080 横屏构图。复用 QuestUi 的铜金框、木棕细边、羊皮纸表头、深海蓝行和朱砂选中状态，商品图标复用 IconLib。

四类标签为商货、异兽、草药、渔获。标题显示 cargoUsed()/holdCap()；列为物品名称、持有数量、本港单价。商货靠港显示 goodPrice，海上显示“靠港查看”；其他分类显示真实 Catalog 卖价。使用 Catalog 的“象牙”等实际名称，不照抄示例误字。停泊时十一行可视，分类各自记忆滚动位置。

保留原 listItems 的显示条件和点击回调：商货靠港进入原行情/交易页及返回路径；异兽、草药、渔获靠港点行卖出一件并保存。海上点行只选择，保留“丢掉选中 x1”及不可恢复提示。未修改容量、库存、价格计算或买卖/丢货方法。

只运行 core/lwjgl3 compileJava；未运行游戏、截图、APK、打包或发布，未修改版本。
