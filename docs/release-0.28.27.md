# v0.28.27 — HUD map dialogue island

1. 情报移至小地图左下角，点击打开原情报面板；点击小地图仍打开全图。
2. 南海地图标题框按标题与副标题的实际文字宽度收紧。
3. 航行 HUD 移除银两资源格，保留粮草、耐久、船员；港口等页面继续显示银两。
4. 自动航行按钮仅保留文字，地图选点功能保持可用。
5. 底部对话框改为居中窄栏，移除「点击继续」提示；点按推进、单侧立绘与目标按钮保留。
6. 战船发现等航行消息在上方居中展示，采用主线任务卡同款纸底与红色标题条。
7. 岛旁浮动入口改为「探索」，不重复显示岛名和副标题；探索与起锚同列上下排列，原登岛搜采和抛锚/起锚功能保留。

## 逐项验证

真实 GL 和输入测试在 1280×720、1600×720 下均通过：

| 项目 | 验证结果 |
| --- | --- |
| 1 | 情报位于小地图左下，实际点击打开情报；旧角标移除，全图入口有效。 |
| 2 | 标题框按字体测量收紧，文字完整，标题区域不触发导航。 |
| 3 | 主 HUD 无银两格，其余资源实时刷新；实际打开港口确认银两仍显示。 |
| 4 | 自动航行仅有文字子节点，实际点击仍打开地图。 |
| 5 | 对话栏宽度不超过 940，居中且小于视口的 80%；无继续提示，文字换行不裁切，推进和目标按钮有效。 |
| 6 | 战船发现提示水平居中，纸底与红色标题条使用主线卡样式。 |
| 7 | 探索在起锚上方同列，浮动文字仅「探索」；实测登岛、关闭、起锚、重新抛锚与港口入口。 |
