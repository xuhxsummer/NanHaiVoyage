## Technical target (go hard)
Implement the strongest practical stack in libGDX 3D for Android:
1. Custom water fragment/vertex shaders (not flat colored slabs).
2. Multi-octave Gerstner or equivalent swell + chop displacement (or GPU vertex anim).
3. Animated normal maps (tile + scroll) if textures exist; otherwise generate strong procedural normals and **document** the texture slots for user-supplied maps.
4. Fresnel + sun/sky specular; optional simple reflection (planar/SSR-lite) if stable.
5. Depth-based color (deep vs shallow), horizon fade into sky.
6. Whitecaps + ship wake foam with speed-scaled intensity; soft edges.
7. No z-fighting between water layers.
8. Perf: aim playable on mid Android with quality toggle; **do not** use the toggle as an excuse to ship a fake-looking default.
