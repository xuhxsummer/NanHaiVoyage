## A) Combat look-drag inverted (bug)
Ref: `assets/ui-refs/20-combat-look-invert.jpg`

## B) Left stick = thrust + steering（轻松好开）
Today: stick mostly turns; right **加速/减速** required to move — awkward.

New default:
- Stick **forward** = thrust (farther = faster; small deadzone)
- Stick **left/right** = steering (easy, not huge turning circle)
- Stick **release** = coast / gradually slow (no hard brake)
- Stick **pull back** = gentle slow-down only (weak or no reverse)
- **Do NOT** add right-hand 冲刺/满帆. Remove or demote hold-to-accelerate as the only way to move; accel/decel buttons can be hidden or kept as optional fine control only if needed — user said 右手不做冲刺满帆.

Auto-sail unchanged in spirit (still goes to target). Manual stick should drive without requiring accel button.

## C) Anchor near ports/islands
- Show **抛锚** button only when near a port or island (use existing dock/island ranges).
- Without anchoring: ship **keeps drifting** (light coast/current) and can float out of interact range.
- With anchor: ship stops so player can stably open port/island UI.
- Leaving / weighing anchor: hide button when out of range; if anchored and somehow forced out, clear anchor.
- Persist mid-session is enough; save flag optional if easy (`anchored` bool).

Wire carefully with existing click-to-open port/island menus: prefer “near + anchored” or keep click-open but drifting makes it harder without anchor — implement so intent is clear (toast: 抛锚后停稳再经营 / 未抛锚船在漂).
