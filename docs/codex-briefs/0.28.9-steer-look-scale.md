## 1) Steering inverted when nearly stopped
**Bug:** When the ship is stopped / near-zero speed, dragging the bottom-left helm/joystick **left** turns the ship **right**, and right turns left. Feels wrong. While moving it may feel OK — fix so **screen-left input always yaws the bow left** (player expectation), including speed≈0, docked undock start, and reverse/decel cases.

Likely touch points:
- `VoyageScreen` virtual joystick → `g.steerInput` (-1..1)
- `GameState` heading integration: `headingDeg += steerInput * TURN_RATE * …`
- Any camera/heading sign flip that only appears when velocity is low (e.g. using velocity heading vs control heading)

Verify on desktop smoke if available; document the sign convention in a one-line comment.

---

## 2) Drag-to-look camera (release = snap back)
While sailing **or** auto-sail, player can **drag on empty sea view** (not on HUD buttons / joystick / accel) to temporarily look at sky, water, sides.

Rules:
- Finger/mouse down + drag on the 3D voyage view offsets chase camera yaw/pitch (orbit around ship).
- **On release**, smoothly return to the normal chase camera (behind ship) within ~0.25–0.4s.
- Do not fight steering: if touch starts on joystick/HUD, it is not a look drag.
- Works during auto-sail and manual sail; combat chase distance can keep working (look offset on top of current distance).
- Implement in `VoyageWorldRenderer` chase update + input in `VoyageScreen` (or a small helper). Clamp pitch so you cannot flip under the sea absurdly; allow enough up to see sky and down to see nearby water.

---

## 3) World / port scale — ship must not dwarf harbors
**Problem:** In chase view the player junk looks **bigger than** the entire 扬州 port mesh (see user screenshot). Unreasonable.

Fix approach (pick the strongest practical combo):
- **Prefer enlarging port/island meshes** (and spacing if needed) so a harbor reads clearly larger than one ship; and/or
- Slightly reduce player ship model scale if ports already dense;
- Keep collision / dock radii / enter-port distances consistent with the new visual scale (update Catalog radii or render scales together — no “pretty but can’t dock”).
- Minimap and world-map markers should still make sense.
- After change: standing near 扬州, ship should look like a vessel next to a **town**, not a giant next to a toy diorama.

Chase camera distance (`SAIL_DISTANCE` etc.) may need a small bump so framing still shows ship + harbor.
