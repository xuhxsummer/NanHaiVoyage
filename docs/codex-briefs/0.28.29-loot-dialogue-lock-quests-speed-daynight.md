## 2) Dialogue vertical blank — NOT shrink whole panel wrongly
User marked arrows on parchment: **too much empty space above/below a single line**. Prior fix that shortened the whole dialogue frame was wrong.

Correct approach:
- Keep dialogue panel / bust layout roughly as now (wide enough).
- **Tighten parchment content area** so a single line sits with modest pad (e.g. paper height ~72–96 instead of fixed `210`, or top-align body with small padTop/Bottom). Do **not** leave a huge empty parchment block for 1-line lines.
- **Multi-line / long lines**: do **not** grow a tall static block. Use a **horizontal marquee / scroll ticker** (same idea as top status marquee) so one line of scrolling text shows the full sentence. Prefer marquee whenever text would wrap to 2+ lines or exceed width.
- Busts stay; title/header/footer unchanged in spirit.

## 3) Lock button missing for merchant / warship
Today `btnLockPirate` only visible when `g.pirateAlive && !g.combatLock` (`VoyageHud.lock` labeled「锁定海盗」). Merchant is tap-only; warships have no lock button — player gets shot with no way to engage.

Fix:
- Show a **「锁定」** button whenever there is a lockable target in range and not already locked: pirate **or** merchant **or** hostile/in-range warship (pick nearest sensible target).
- Wire click: pirate → `lockPirate()`; merchant → `lockMerchant()`; warship → add lock/engage API if missing (hostile + chase/fire like existing combat rules).
- Keep「取消锁定」when `combatLock || merchantLock` (and warship lock if added).
- Still allow tap-on-ship lock as now; button is the missing HUD affordance.
- Label:「锁定」not only「锁定海盗」.

## 5) Other ships / pirates too fast
Player `Catalog.MAX_SPEED = 150`. NPCs:
- traders/merchants cruise `58 * (1+SHIP_SPEED%) * (hostile?1.55–1.6)`
- pirate `PIRATE_SAIL_SPEED = 100` + `chaseSpeed = max(cruise, |playerSpeed|+35)` — always outruns player
- warships similar (~90 + chase)

Tune so mall hull variants still differ but player can catch / keep up:
- Cap NPC cruise ≈ **0.55–0.70 × player max** for same hull class (keep relative SHIP_SPEED differences).
- Hostile flee/chase multiplier closer to **1.1–1.25**, not 1.6.
- `chaseSpeed`: follow with small lead (**+8…+15**), not +35; lower `PIRATE_SAIL_SPEED` / warship cruise accordingly (~70–80).
- Feel: player at mid stick can stay with merchants; locked chase still pressuring but not teleport-fast.

## 6) Day ↔ night must blend (no hard cut)
User sees whole screen snap day↔night. There is already `dayness` lerp in `VoyageWorldRenderer` but transitions are short / plateaus feel binary; clock label snaps `白天`/`夜晚` at 06/18.

- Widen dawn/dusk windows to **~2 hours** each side; smooth continuous curve (no flat day then sudden drop).
- Ensure sky clear color, water `u_night`, ambient, directional light, ship lighting all use the **same** smooth factor every frame.
- Optional HUD: during blend show「黄昏」/「黎明」instead of hard flip, or keep 白天/夜晚 but drive visuals from smooth factor only.
- Verify no other path forces binary night (postFX, second clear).
