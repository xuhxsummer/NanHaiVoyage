# Part A — Voyage feel (device feedback on v0.28.8)

## A1) Steering inverted when nearly stopped
When speed ≈ 0, helm/joystick left turns the ship right (and vice versa). Fix so **screen-left always yaws bow left**, including stopped, undock start, and slow speed.
Touch: `VoyageScreen` stick → `aimHeading` / `steerInput`; `GameState` heading integration. Document sign convention in a one-line comment.

## A2) Drag-to-look (release snaps back)
While manual or auto sail, drag on empty 3D sea (not HUD / joystick / accel) to orbit look at sky/water/sides.
- On finger/mouse **release**, smooth return to chase cam (~0.25–0.4s).
- Clamp pitch; don’t steal joystick/HUD touches.
- Implement via `VoyageWorldRenderer` chase + `VoyageScreen` world input.

## A3) Port/island scale vs ship
Ship currently dwarfs 扬州 harbor in chase view (user screenshot). Enlarge port/island meshes (and/or slightly shrink ship) so a harbor reads as a **town next to a vessel**. Keep dock/collision/enter ranges consistent. Nudge `SAIL_DISTANCE` if framing needs it.

## A4) Main chase view: **real 3D** ports/islands matching Gemini art (NOT billboards)
User clarification (2026-09-08): She does **not** want flat “picture cards / billboards” stuck in the sea. She wants **立体** harbors and islands in the chase cam that look like the Gemini reference paintings.

**Allowed:** Rebuild/enrich procedural libGDX 3D meshes (layered mountains, roofs, piers, trees, sand, rocks) using each `port_*.png` / `island_*.png` as **visual reference** — same approach as the existing Tang port redesign, but driven by the new art and scaled so harbors read larger than the ship (with A3).

**Not allowed as the main solution:** camera-facing quad / “立牌” with the PNG as the only silhouette.

**Out of scope for this pass:** external Meshy/glTF AI pipelines. Stay in-repo procedural (or simple authored meshes in code). Optional: use the painting as a **supporting** albedo on roofs/terrain patches if it helps, but the readable shape must be real geometry.

Keep collision / dock / enter-island behavior correct after rescaling.

## A5) Idle ship still has light water ripples
User addendum (2026-09-08): Even when the ship is **stopped** on the open sea (speed ≈ 0, not only when moving), the water around the hull should keep a **subtle ripple / idle wake / local disturbance** — not a dead flat mirror. Keep it light; full speed wake can stay stronger. Do not require player input. Touch water shader / wake path in `VoyageWater` / `VoyageWorldRenderer`.
