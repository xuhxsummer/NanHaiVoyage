# A) Pirate / warship AI (plain user goal)

1. Locked pirate/warship **flank** the player and fight at gun range — not straight bow-ram / glue.
2. At **≤50% HP**, **withdraw** while returning fire (open water away from player).
3. **Pirate fiercer/closer**; **warship steadier/standoff**; keep warship probabilistic ram.
4. Merchants: flee + fire when hostile; never chase.
5. Preferred distance ~60–90% of `PIRATE_RANGE`; unlock may short continue-chase ~2–3s then cruise.

Files: `GameState.updateCombat`, warship AI, chase helpers. See also earlier notes in `0.28.25-pirate-warship-ai.md` if useful.

# B) Contextual tips — 做到哪提示到哪

## Rules (locked with Summer)
- **Per tip type, once per armed cycle** — e.g. first pirate shows lock tip; second pirate in same cycle does **not**.
- **Debug frequency (current ship)**: re-arm **all tips on every login** (each time user enters voyage after login). So testing is easy; same tip still only once until next login.
- Later production can switch to once-per-account/install; for now implement **login reset**.
- Tips are **short**, non-blocking (prefer toast / small tip bubble near relevant control — not a full HOWTO wall). Dismissible; completing the taught action auto-dismisses.
- Shorten or skip the old first-run full-page HOWTO body so it does not compete (keep a tiny optional howto or remove auto-show; situational tips are primary).

## Tip steps (first-time triggers)
| id | When | Copy (Chinese, one line) |
|----|------|--------------------------|
| `stick` | Voyage start / first seconds with no move input | 推动左下摇杆，控制船只航行 |
| `dock` | First time near port/island with anchor/dock available | 靠近港岛后，点船旁「抛锚」或「停靠」 |
| `pirate_lock` | First pirate alive / first time lock UI relevant | 点海盗船或「锁定」开始交战 |
| `port_trade` | First successful dock at a port (menu open) | 在港口可补给、买卖货物 |
| `quest_card` | First time quest cards visible on HUD | 点右侧任务卡，查看剧情与目标 |

Mark each id shown for this login cycle (prefs or in-memory cleared on login). Never re-fire same id until next login re-arm.

## Implementation hints
- Hook near existing: joystick, near-port hint, pirate spawn / lock buttons, port overlay open, quest card.
- Prefer `GameState.toast` or a small dedicated tip actor on `VoyageHud` with highlight optional.
- Persist “shown this login” in session fields reset in voyage `show()` / after login; or prefs keyed by session — simplest: clear tip flags when `VoyageScreen` starts from login.
