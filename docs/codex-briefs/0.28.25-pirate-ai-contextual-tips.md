# A) Pirate / warship AI
Flank chase at ~60–90% PIRATE_RANGE; ≤50% HP withdraw while firing; pirate fiercer, warship steadier + probabilistic ram; merchants flee+fire only; short post-unlock chase OK.

# B) Contextual tips
Per tip id once per login; re-arm all tips every login (debug). Tips: stick / dock / pirate_lock / port_trade / quest_card. Short non-blocking; shorten/skip old HOWTO wall.

# C) Medium ram / sink feedback
Ram: hull rock, local splash, hurt flash, optional camera punch; no wood SFX.
Sink: 1.5–2.5s tilt/bubbles, follow cam; loot card after sink beat; keep Water Splash 02 + BGM duck.

# D) Quest pace — claim unlocks next immediately
- On reward claim: **immediately** open next quest dialogue (or short「下一程已开启：××」) and refresh quest cards to the new active objective — no lingering「待前序领奖解锁」as the only feedback.
- Locked next card copy: clearer「完成上一程并领奖后开启」; after claim, card becomes tappable with real goals (concrete actions).
- Prefer concrete objective text over dry unlock waits.

Files: quest claim flow in `VoyageScreen` / quest defs.

# E) Dialogue paper cutouts (半身像)
Layout in quest dialogue UI:
- **Left**: NPC speaker bust (掌柜、船医、画师、老水手… map by dialogue speaker name).
- **Right**: player「我」bust.
- Active speaker brighter / slight scale; other side dimmed.

**Art (Codex generates assets this pass):**
- Style: Tang / nautical game-friendly **paper-cutout / flat illustration half-body**, transparent PNG, consistent palette with voyage UI (parchment/ink/sea), ~512px tall busts.
- **NPCs**: one bust each for recurring roles used in quests (at least: 掌柜, 船医, 画师, and a generic 老者/水手 fallback for unknown names).
- **Player「我」**: **4 busts bound to captain avatarIndex 0–3** (same identities as existing avatar portraits — enlarge/extend to half-body). Dialogue right side uses `g.avatarIndex`.
- Put under e.g. `android/assets/ui/dialogue/` (`npc_掌柜.png`, `player_0.png` …). Wire `QuestDialogue` (or equivalent) to show images by speaker.

If image gen tool unavailable in Codex, draw simple stylized placeholder busts (colored silhouettes + face dots) that still read as paper cutouts — but prefer real generated PNGs.
