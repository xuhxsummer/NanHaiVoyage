# NanHaiVoyage — Captain profile full-screen page (0.28.9)

## User intent (2026-09-08)
Replace the current **top-left avatar popup** (`CaptainMenuPanel` modal ~752×560) with a **full-screen overlay page** (same family as other voyage full panels ~1296×832 / stage-filling), layout:

```
┌─────────────────────────────────────────────┐
│  Title · 世界暂停                    [关闭] │
├──────────┬──────────────────────────────────┤
│ LEFT     │ RIGHT                            │
│ nav list │ selected feature content         │
│          │                                  │
└──────────┴──────────────────────────────────┘
```

### Left nav (default select 个人信息)
1. **个人信息** — nickname + avatar picker (primary new feature)
2. **存档** — 保存进度 / 读取存档 (move here from old popup; keep same VoyageScreen callbacks)
3. **调试** — 满级账号 (keep existing fill-max behavior; can hide later)
4. **账号** — 退出登录

### 个人信息 (right pane when selected)
- Show current circular avatar (large) + nickname field.
- **Nickname**: editable TextField; persist in local save; show on HUD near avatar if space allows (or at least in this page + captain menu title). Default e.g. `船长` if empty.
- **Change avatar**: grid of **4** portraits (`android/assets/textures/avatars/avatar_01.png` … `avatar_04.png` — may arrive later; use placeholders / IconLib until files exist). Tap to select; persist `avatarIndex` 0..3 in save; top-left HUD circle updates immediately.
- Persist across load/save like other GameState fields.

### Behavior
- Tap top-left HUD avatar → open this full-screen page (not the old small dialog).
- Opening still **pauses** the world (same as current captain menu).
- Close returns to voyage HUD.
- Do **not** break smoke tests that tap `船长` / save / load / 退出登录 — update selectors/names as needed and fix smokes.
- Visual style: match existing Tang/paper QuestUi panels (login / cargo / my-ship family), not a system dialog.

### Out of scope
Water, ports 3D, combat. Port/island icon wiring is separate (0.28.8). Avatar PNG art may land after code — ship with placeholders OK.

### Process
- Model: `gpt-6-astra` max, `/fast` off, visible terminal.
- First reply: quota OK or usage-limit/reset.
- When done: `./scripts/release.sh 0.28.9 "船长全屏页：换头像与昵称"`
- Report Release URL.
