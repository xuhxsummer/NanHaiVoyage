## 1) Pirate toast but ship not visible (bug)
Root cause likely: `spawnPirate` uses `trafficSpawn` → `Catalog.NPC_SPAWN_MIN..MAX` (~800–1000). Chase cam `SAIL_DISTANCE=185`, combat pull `COMBAT_DISTANCE=600` — pirate often beyond what player sees; only minimap scarlet dot.

Fix:
- When toasting「外海发现海盗」, pirate hull must be **visible on the 3D horizon** (not only minimap). Prefer pirate spawn ring inside a **visible band** (suggest ~420–620, still not pop-in-front of player; tune so model is on-screen at combat camera). Merchants/warships may keep the far traffic band.
- Also mark pirate on **南海海图** (`WorldMapOverlay`) as a red ship/dot when `pirateAlive` (currently missing).
- Keep minimap red enemy dot.
- Optional: if still far, briefly ensure combat camera pull when pirateAlive (already intended) so silhouette appears.

Files: `GameState.spawnPirate` / `trafficSpawn`, `WorldMapOverlay`, `VoyageWorldRenderer` if cull issue.

## 5) Mutual collision push (no teleport jump)
Current `resolveCollision` / `ensurePirateSeparation` mostly **teleports/slides the player** off overlap — feels like instant jump.

Want realistic mutual force:
- On hull contact (player↔pirate/merchant/trader/warship): along contact normal, **both** bodies move apart a bit (I push them forward/aside; I get pushed back slightly). Side hit → lateral separation + slight retreat.
- Prefer continuous separation impulse each frame while overlapping (clamp max step) rather than one big snap.
- Keep existing ram **damage** + cooldown; this item is **positional physics**, not changing damage %.
- Apply to traders/warships roster too, not only legacy pirate/merchant.

Files: `GameState.updateShipImpacts` / `resolveCollision` / `move` / new helper e.g. `separateShips`.
