## Bug
Screenshot: `assets/ui-refs/20-combat-look-invert.jpg`.
In pirate/combat (camera pulls to COMBAT_DISTANCE, 「锁定海盗」 shown), horizontal look-drag is inverted: slide left → view goes right.

## Hooks
- `VoyageWorldRenderer.dragLook`: `lookYaw = lookYaw - dx*180f`
- Combat when `pirateAlive || merchantLock` uses farther chase cam
- `VoyageScreen` WorldInput feeds normalized dx from screen deltas

## Fix
Make horizontal drag match natural expectation in sail AND combat (slide left looks left). Prefer flipping the yaw sign in `dragLook` (or only when combat zoomed) after verifying sail mode still feels right. Minimal diff.
