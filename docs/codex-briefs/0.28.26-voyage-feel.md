## 1) Stick release & ship-type steering
- After releasing left stick: coast/slowdown curve feels natural (not instant stop, not too mushy). Tune existing gradual slowdown if present.
- Turn rate / turn radius differs slightly by hull class (larger ships turn slower, small boats snappier) using Catalog ship stats.

## 2) Near-port alignment
- Stronger near-port/island drift or gentle magnetic assist so docking lines up easier without spinning forever. Keep no-teleport leave behavior from 0.28.23.

## 3) Cannon light feedback
- On player fire: tiny hull kick / muzzle flash spark; keep slowed fire rate for SFX match. No wood-break SFX.

## 4) Lock & combat camera
- On lock: short cue (soft UI pop or pulse on lock marker).
- Combat camera pull-out / return-to-chase: smoother lerp (less snap).

## 5) Anchor / UI press
- Anchor drop/raise: short punch or SFX beat.
- Buttons: brief press scale so taps feel acknowledged.

## 6) Sea motion (light)
- Slightly clearer bob with waves; wake/foam scale with speed if cheap.

## 7) Day / night sky (simple, not full atmosphere)
Night is currently too subtle (clock text changes more than the sky).
- **Day**: brighter blue / warm daylight; sea a bit brighter.
- **Dusk** (optional short blend): warmer orange horizon.
- **Night**: darker sky + darker sea tint; simple stars and/or faint moon; UI can stay readable (rail labels already day/night aware).
- Blend with in-game clock (06:00–18:00 day per existing rules); no hard cut at the hour.
- Do **not** implement full physical atmospheric scattering — color ramps + dim + stars/moon only.
