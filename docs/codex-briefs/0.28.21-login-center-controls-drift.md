## A) Login form truly centered
`LoginScreen` uses hard `place(formPanel, 504, 352, 912, 304)` on a fixed design size — looks left on some aspect ratios.
Re-center the **login/register form panel** (and related fields) horizontally (and keep vertical sensible). Also ensure success/update modals stay centered (`centerModal` after pack/layout). Gate progress bar can stay bottom-centered.

## B) Right accel/decel — hide or demote
User: 「方向盘和右边加速减速按钮没有什么变化」.
0.28.17 already made left stick thrust+steer; right buttons still visible as fine control.
**This build: completely REMOVE 加速/减速 buttons from the HUD** (not optional fine control). Left stick alone must drive. Do not add sprint. Optional: keep keyboard W/S if already there.

## C) Stronger drift when near port/island without anchor
User: not anchoring near land barely drifts away.
Increase coast/current drift when `canAnchor()` / in land range and **not** `anchored`, so ship clearly slides out of interact range if player idles. Keep anchored = fully stopped. Tune so it's obvious in ~few seconds without feeling broken in open sea (open-sea coast can stay milder).

## D) Anchor button beside the ship
Move 抛锚/起锚 beside the player ship (world-to-screen). Still only visible in port/island range (or already anchored).


## E) Dock hint + anchor stacked beside ship
「广州港 / 点击停靠 · 港口经营」and 抛锚 are **one vertical stack beside the ship** (一上一下: e.g. dock prompt above, 抛锚 below — or reverse if clearer). Follow the ship on screen. Not top HUD. Same for islands.


## F) Autosave every 15s
Overwrite local account save periodically while logged in (voyage / menus). **Does not grow APK** — local prefs/files only. No new manual-save UX required; remove or keep any existing save button inert/hidden if present. Debounce: skip if no dirty state when cheap to detect.


## G) Camera mode in captain/avatar settings
Top-left 船长/头像 menu settings: add **视角** choice —
- **默认视角**: current behavior (sail distance chase; pull to `COMBAT_DISTANCE` in pirate/merchant combat; restore after combat).
- **上帝视角**: always use combat-style pullback (`VoyageWorldRenderer.COMBAT_DISTANCE`), whether sailing, in combat, or after combat ends. Never snap back to sail distance while this mode is on.

Persist in prefs (e.g. `nanhai-settings` key `cameraMode` = `default`|`god`) and/or account save if easy. Apply immediately when toggled. Wire in `VoyageWorldRenderer` wanted-distance logic (~line using SAIL_DISTANCE vs COMBAT_DISTANCE).
