## Goal
Replace the static full-screen login background (`textures/login/harbor-hd.png` Image) with a **lightweight animated** login scene matching:

`assets/ui-refs/17-login-dynamic-ref.png`

Must feel alive: **moving seawater** + **sails/flags that sway**. Keep username/password, 登录/注册, local-account flow working.

## Approach (preferred)
Layered 2D / Scene2D (not a full voyage 3D world on the login screen):
1. Author or extract layers (sky, distant coast, sea, hull, sails/flags, foreground deck props). If no separate art files exist, **slice/mask from the reference or current harbor art in code/tools** and document paths under `android/assets/textures/login/`.
2. Sea: slow UV scroll and/or a small ripple/distort shader on the water region (mask if needed). Reuse ideas from voyage water only if cheap on mid Android; login must stay light.
3. Sails/flags: separate actors with gentle sine sway / scale pulse (wind).
4. Optional polish: slow cloud drift, subtle lantern sway, looping seagull sprites if cheap.
5. UI chrome: tighten toward the reference (title treatment, input bars, 登录/注册 buttons) without breaking existing login/register logic. Stub 客服/公告/切换账号 as simple dialogs or no-ops with toast only if already present — do not block on full CS system.
