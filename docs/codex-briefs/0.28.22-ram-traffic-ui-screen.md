## 1) Login: hide center form until version gate finishes
While bottom progress / version check runs, **hide** the center login/register panel (the area user circled — username/password/buttons). Only show after check completes (latest / offline timeout). Update popup can still appear on top. Ref prior: `LoginScreen` formPanel + gate.

## 2–3) Ship ramming (mutual, not 100%)
Enable **hull collision impacts** between player and NPC ships (pirates / warships / merchants) and among NPCs when fighting.

Damage by relative size (use ship class / hull / Catalog.SHIP_* as “size”):
- **Larger hits smaller**: smaller loses **20%** of its max HP; larger also takes some mutual force (if larger is aggressor vs smaller, still apply reciprocity — user: 力的作用是相互的).
- **Smaller hits larger**: smaller loses **20%** max HP; larger loses **10%** max HP.
- Same size: both **~15%** (pick sensible) or both 20%/10% split — document choice.

Cooldown cooldown so one graze ≠ spam (e.g. 2–3s per pair). Visual/toast optional short「撞击」.

**During combat**, other ships (esp. warships/pirates) have a **probability** to attempt ram — **not 100%** (repairs are expensive). Suggest ~20–35% per opportunity / interval when in close range and hostile. Merchants: see §5.

## 4) Anchor + dock tip: RIGHT of ship, same button size
0.28.21 put them beside ship stacked; user now wants them on the **right side of the ship** (not top of screen), and **same visual size** for both buttons (抛锚 / 点击停靠). Equal width/height, shared style.

## 5) Merchant vs warship AI
- **Merchants**: never **initiate** ram. In combat: **return fire + flee** (increase flee speed — currently too slow; only counterfire).
- **Warships** (pirate / combat hulls): may **probabilistically** initiate ram while fighting.
Clarify hull classification from Catalog (which ships are merchant vs war).

## 6) Horizon traffic mix & rate
Previously ~0–1 pirate + 0–1 merchant. Change to support concurrent mix aiming toward **2 merchants + 2 warships + 1 pirate** as soft caps on/near horizon (not always full — **~25%** chance when a spawn roll fires). Spawns stay in far band (existing NPC_SPAWN_MIN/MAX / horizon) so ships appear in the distance, **not** pop in front of the player. Keep frequency modest (not dense spam). Extend beyond single `merchant` / `pirateAlive` if needed (list of sea entities).

## 7) Top-right rail labels readable
「福利」等 rail text blends into sky — improve contrast (dark outline / shadow / darker plate behind label) for all top-right rail titles in `VoyageHud`.

## 8) Keep screen on in-game
Android sleeps after idle because `FLAG_KEEP_SCREEN_ON` / libGDX `config.useImmersiveMode` alone isn’t enough. In `AndroidLauncher` (and/or window flags while voyage/login active): **keep screen awake** for the whole app session (or at least VoyageScreen + LoginScreen + update download). Other games do this; add it.


## 9) Sink VFX + loot popup
- Sink SFX (locked): Pixabay **Water Splash 02** by Universfield only — no wood-break layer. Play louder + brief BGM duck (~0.5–1s) so combat BGM does not mask it. File e.g. `android/assets/audio/sfx_sink.mp3`.

- When any ship is sunk: play a short **sinking effect** (tilt / settle into water / brief debris) over ~1–2s, then remove. No instant disappear.
- Player loot/plunder from sinks: show a **centered modal/popup** listing rewards (silver/cargo/etc.). Do **not** use bottom toast for loot.

## Shipped (implementation notes)
- **Login gate**: whole center form hidden via named actors (`loginFormPanel/loginTitle/loginLocal/loginUserCaption/loginPassCaption/loginUsername/loginPassword/登录/注册/loginMsg`); revealed on `openGate` (check finished / 6.5s offline timeout); update dialog overlays above the gate.
- **Ramming**: `GameState.updateShipImpacts` — per-pair 3s cooldown; damage documented as smaller 20% / larger 10% of own max HP, same size 15% each (力的作用是相互的); ram kills grant no loot; toast「撞击」+ cannon thud. Player-vs-pirate/merchant share one cooldown; trader and warship slots each have their own.
- **Warship probabilistic ram**: hostile warships roll `WARSHIP_RAM_CHANCE = 0.25` per 3s opportunity inside ~45% PIRATE_RANGE, then lunge + resolve.
- **Merchant AI**: never initiates ram; when hostile, keeps counter-firing and flees at 1.55× speed toward the mirror point away from the player; skips port trading while fleeing.
- **Hull classification**: traders spawn from merchant-class hulls {小商船, 漕舫, 货舶}; warships from combat hulls {斗舰, 海鹘} (`TraderData`/`WarshipData` in shared, runtime-only, not persisted).
- **Traffic mix**: roster `2 traders + 2 warships` on top of the legacy pirate + single merchant; each spawn timer fires a `SPAWN_ROLL_CHANCE = 0.25` roll; spawns stay in the far 800–1000 band (`trafficSpawn` now also respects roster separation); despawn beyond 1.4× horizon.
- **Ship-right anchor/dock pair**: `location` (180×64) at ship-right +56, `anchor` (180×64) immediately to its right; projected per frame in HUD design space; hidden when paused/off-screen.
- **Rail contrast**: translucent dark `plate` drawable (VoyageHudChrome) behind all six top-right rail titles.
- **Keep screen on**: `FLAG_KEEP_SCREEN_ON` added to the window for the whole app session in `AndroidLauncher`.
- **Sink VFX**: `GameState.Wreck` (4 slots, 2.5s) — tilt to 72°, quadratic submerge, per-wreck sway; rendered in `VoyageWorldRenderer` from the shared ship models; despawn only when the timer expires (never instant-vanish). All kill paths (cannonballs, ram sinks, NPC-vs-NPC) create wrecks.
- **Sink SFX**: `assets/audio/sfx_sink.mp3` = Pixabay "Water Splash 02" by Universfield (only layer). `VoyageAudio.playSink()` plays at full volume and ducks current BGM to 30% for 0.9s, restored via `VoyageAudio.update(delta)` from VoyageScreen.
- **Loot popup**: `LootGain` records silver/good/extra on player plunder kills; `VoyageScreen` opens a centered LOOT overlay (世界暂停) listing rewards with「收下」; bottom toast no longer carries loot details.
- **release.sh fix**: ignore-pathspec git add no longer aborts the script when `assets/saves/` exists (0.28.21 postmortem).
