## Behavior

### BGM (Music)
- Login / title: `bgm_login` loop (Quiet Water is ~30s — loop OK).
- At sea (voyage, not in port UI, not combat): `bgm_sail` loop, moderate volume.
- Port / island dock UI open (or anchored at port): `bgm_port` loop.
- Pirate combat: `bgm_battle` loop; on combat end restore sail (or port if still docked).
- Crossfade or stop-then-play is fine; avoid stacking multiple BGM.

### Ambient
- `sfx_waves` loop **quietly** while sailing at sea.
- Quieter or muted when: in port/island UI, anchored at dock, login/menus, full-screen panels.
- Must not drown BGM.

### SFX
- Cannon fire: play `sfx_cannon` on each shot. **Slow player/pirate fire interval** so short cannon SFX can finish (keep projectiles; not pure DPS redesign). Player vs pirate per-shot damage stays separate; upgrades still raise damage.
- Silver gain/spend / reward: `sfx_coin`.
- Major UI buttons / panel open-close taps: `sfx_ui` (don't spam every hover).

### Settings (minimal)
- If volume toggles already exist, wire music + SFX. If none, add simple mute or master volume only if cheap; otherwise hardcode sensible volumes and note in Release notes.
