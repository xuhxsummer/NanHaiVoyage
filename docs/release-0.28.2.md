# 0.28.2

一键满级账号：船/异兽/草药全开。

船长菜单新增「满级账号」。一次确认后全开当前本地账号的船只、异兽和草药，装备海鹘；每种异兽、草药至少保留一件，基础货舱扩至足够容纳全部现有物品。银两至少 99999，船体、补给、当前船员补满，补全异兽发现与银两峰值计数。没有鱼类发现字段，因此保留原有渔获。操作刷新界面并自动保存，确认文案说明会覆盖本机存档。

保留已有货物、账号密码和其他账号的本地离线存档。修复读取存档时把船员的船只加成重复计入基础编制的问题。

验证：隔离临时账号的 OpenGL 集成测试覆盖取消、确认、自动存档、读取、货舱容量、船员上限、密码与其他账号隔离、重复执行；3,645 次碰撞回归及字体覆盖检查通过。测试入口：`:lwjgl3:maxAccountSmoke`、`:lwjgl3:geometryRegression`。
