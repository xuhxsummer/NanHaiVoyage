# 0.28.10 — 海图、世界间距与福利兑换

- 港口与岛屿缩略图在加载时去除与图像边缘连通的白色、灰色棋盘格和浅纸色底，保留内部屋顶、船帆与沙滩。处理后的 256×256 纹理支持 Android GL 上下文恢复。完整海图不再绘制矩形卡框；原有图标与文字点击范围保留。圆形小地图使用同一组透明缩略图。
- 世界从 4800×3600 扩大至 9600×7200，全部 21 港口与 13 岛屿坐标精确翻倍。小地图地理底图和视野范围同步翻倍；完整海图按世界尺寸归一化投影。船体、港岛实体大小、碰撞与停靠距离保持物理尺度，港岛之间距离加倍。出生点使用新的港口坐标；海盗遭遇半径仍是船周围的局部距离，边界限制自动使用新的世界大小。相机与水面以船为中心，其现有覆盖范围仍可覆盖可见水面，无须加倍网格或远裁面。
- 旧存档通过 worldVersion 一次性迁移。海上坐标翻倍；停靠存档随港口移动并保留船与港口的局部偏移。新存档写入版本 2，再次读取不会重复缩放。
- 福利按钮打开全屏兑换页面，暂停世界。兑换码去除首尾空格后精确匹配：666 奖励 666 银两，888 奖励 888 银两。每码每存档限领一次；奖励与领取状态立即写入当前账号本地存档。无效码、重复领取和银两整数溢出均不发奖。
- 删除无操作时底部的祝福语及空框；短暂的操作结果消息仍可显示。
- 两张右侧任务卡的标题左右留出装饰安全区，长标题省略，避开左侧金色角标。

验证：几何回归覆盖 3,672 次高速碰撞、全部船型与港岛停靠、34 条从扬州出发的自动航线、旧档迁移与兑换规则；图像 GL 检查覆盖全部 34 个港岛的透明度与完整轮廓、50 张图的受管重载、34 个海图目标及边角点击；交互 smoke 覆盖兑换真实账号文件保存和重复领取、无祝福语页脚、任务标题留白，以及 13 个全屏页面在 1280×720 与 1600×720 下的暂停和关闭。字体检查无缺字。
