## 2. 一句话

武则天时期，玩家驾船跑南海（小地图、十来个港口）：港口买卖赚差价，途中耗补给、可能与海盗开炮，靠岸探岛发现山海经异兽与草药。船可维修、可升级（炮火、货舱、船员等）。后期可买船，派船自己去赚钱。

类型：**探索 + 跑商 + 海战**，后期带一点船队托管。不是纯操帆模拟，也不是纯文字冒险。

### 世界观

- 时代背景：**武则天时期**（武周 / 唐）。
- 空间想象：一张 **南海小地图**，**十来个港口** + 岛屿（历史氛围服务玩法，不追求严格考据）。
- 奇珍异兽参考 **《山海经》**（神貌、产地可改写成南海岛屿，不要求原文逐条复刻）。
- 岛上另有 **草药**（本草/药材，可与异兽并列作为探索收获）。

### 核心玩法（玩家原意）

1. **探索**：船可靠岸，上岛发现《山海经》异兽和草药。**v0.1 靠岸后用菜单搜采**；上岛自己走列为后期。
2. **损耗**：航行消耗物资（补给）。**补给空了直接失败**。**补给只能回港补充**，海上不能把货物吃成补给。
3. **海战**：航行途中 **随机遭遇** 海盗；点选敌船锁定后自动连续开火。航行由玩家自己开船。打赢：**抢货物或银子**，偶尔 **缴获更好的炮或船部件**。**v0.1 这些缴获先当货物卖掉**；装备栏/装上自己船列为后期。
4. **跑商**：港口间买卖赚差价。普通商货 **种类要多**（经营游戏体量），各港 **固定差价、不随时间变**；另可卖异兽与草药。
5. **维修**：船会损坏（尤其被打之后），回港可维护/修理。
6. **升级**：船可强化，至少包括 **炮火、仓库（货舱）、人数（船员编制）** 等。货舱满了 **不能再买**，得先卖掉或丢掉。**海上能丢货，丢了就没了**；从 **货物列表里选择丢掉哪一种**。
7. **船队（后期）**：可以自己买船，让船自己去赚钱。
8. **节奏**：一趟航行 **几分钟**，适合碎片时间（港间距、遇敌频率按此压）。
9. **天气**（v0.1 就要）：风 **只改变航速**（顺风快、逆风慢），**不把船吹偏**；雨、雾让 **海图看不清**（不另加发现难度）。
10. **图鉴与产出**：异兽、草药都进图鉴（**单独界面，随时能打开**）；都可在港口卖掉赚钱；草药 **后期** 可使用（补状态或炼药）。**v0.1 草药只卖钱、不使用**。异兽不养成、不参战、不看家。发现即获得可卖货物，不是抓宠物。

## 4. 范围分层

### 4.1 v0.1 必须能玩（建议）

目标：装上 APK 后登录，在南海小地图上自己开船，十来个港口间跑商（货种要多），途中扣补给、随机遇海盗并自己开炮，可登岛发现异兽/草药（图鉴+可卖，草药能用），回港花钱立刻修船升级，能存档。

- 登录 + 读档/存档
- 一艘玩家船（耐久、货舱、补给、火炮、船员人数）
- 港口可 **修船**（被打后花银子恢复耐久）
- 港口可 **升级** 至少一项（建议 v0.1 先做炮火或货舱一级，人数做成数值即可）
- 多种普通商货（经营游戏体量，具体名单未定）+ 异兽/草药可卖；各港固定差价，不随时间/供需波动
- 南海小地图、约十来个港口；航行扣补给，补给空了直接失败
- 航行途中随机遭遇海盗（非海图关卡）；开炮，打赢继续、打输掉耐久；耐久到 0 船沉则直接失败（必须能修）
- 一座可登岛：发现 1 种山海经异兽 + 可采草药；进图鉴；可带回卖掉；草药 v0.1 只卖钱不使用（使用/炼药后期）
- 触控：俯视海图自己开船，海战自己瞄准开炮；港口/上岛用菜单
- 港与港之间一趟约几分钟（碎片时间）
- 打出可安装 APK

## 5. 核心循环（v0.1）

1. 登录，读到自己的船和存档。
2. 在港口用 **货物列表** 看 **本港价格**；**点开一种货才能看到各港行情**。买货、补补给、修船、升级炮火/货舱/船员。
3. 出航。航行扣补给；可能遭遇海盗，开炮解决；挨打掉耐久。
4. 可偏离航线靠岛：探索，发现山海经异兽与草药：进图鉴，可卖；草药第一版只卖钱。
5. 到其它港口卖货，赚差价，再存档。
6. 补给耗尽或船被打沉：都直接失败，**读档重来**。默认靠港自动存档。

成长感（v0.1）：钱变多、船能修、炮/舱/人能升一级、图鉴多一种。船队托管等有钱有船之后再开。
